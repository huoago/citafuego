# CitaFuego V5 UX scope

This release intentionally reduces interaction complexity without adding new product surfaces.

- Global header: notifications + creation only.
- Bottom navigation: five stable destinations with unified SVG icons.
- Discovery: horizontal Pass/Like gestures only; vertical scrolling remains native.
- Match: user chooses whether to message or keep discovering.
- Profile: commercial and optional tools move to a secondary settings screen.
- Safety: after reporting, blocking is offered as a separate immediate protection choice.

The release keeps existing routes, data, safety controls, chat persistence, membership feature gates, and monetization backends intact.
